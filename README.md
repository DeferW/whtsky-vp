# WHTSKY Servers

Статический сайт Minecraft-сервера, сезон 2: Minecraft 1.21.1 / NeoForge.

## Страницы
- `/` — главная, сезоны и подключение.
- `/how-to-play/` — пустой раздел для новой инструкции.
- `/rules/` — пустой раздел для новых правил.
- `/contacts/` — основатель DeferW (@defer.w) и Discord.

Общие данные — `assets/config.js`. IP не менялся: whtsky.mineserv.ru.
Discord: https://discord.gg/YwaqcRJRg9.

## Просмотр
`python -m http.server 4173 --bind 127.0.0.1`
Откройте http://127.0.0.1:4173/.

## GitHub Pages
Settings → Pages → Deploy from a branch → ветка сайта → /(root).
Сборка не нужна. Относительные пути поддерживают сайт в подкаталоге репозитория.

## Оформление
Две темы; выбор сохраняется локально. Логотип предоставлен владельцем.
Шрифты Oswald и Golos Text загружаются с Google Fonts с системными заменами.
Скин DeferW получен с Ely.by: https://skinsystem.ely.by/textures/DeferW.
Голова показана CSS-слоями исходной текстуры, включая слой головного убора.

Вики и материалы первого сезона удалены из текущей версии сайта.
