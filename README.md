# WHTSKY Vanilla Project

Статический сайт сообщества Minecraft. HTML, CSS и JavaScript без сборки и зависимостей.

## Страницы

- `/` — главная и подключение;
- `/rules/` — проект правил, который необходимо утвердить перед запуском;
- `/contacts/` — Discord и команда;
- `/wiki/` — отдельный модуль вики, пока Work in progress.

## Данные сервера

Заполните `assets/config.js`: название, адрес, версию, Discord и список стаффа.
Пустые значения показываются как «скоро», вымышленные контакты и статистика не используются.
Ссылки Discord должны начинаться с `https://`.

```js
staff: [
  { nickname: 'Nickname', role: 'Администратор', discordUrl: 'https://discord.com/users/USER_ID' },
],
```

Крупная надпись WHTSKY на главной и HTML-метаданные редактируются в HTML отдельно.
Тексты правил — в `rules/index.html`. Перед публикацией проверьте их соответствие правилам сервера.

## Локальный просмотр

Из корня проекта:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173/`. Все пути относительные: сайт поддерживает публикацию
как в корне домена, так и по адресу `username.github.io/whtsky-vp/`.

## GitHub Pages

После отправки файлов в GitHub откройте **Settings → Pages → Build and deployment**:
выберите **Deploy from a branch**, ветку с сайтом и каталог **/(root)**, затем **Save**.
Файл `.nojekyll` отключает обработку Jekyll. Отдельный сервер, npm или секреты не нужны.

Шрифты Oswald (заголовки) и Golos Text (текст) загружаются с Google Fonts; есть системные запасные шрифты. Stengazeta не включён: для размещения требуется веб-лицензия.

Тёмная и светлая темы переключаются в шапке. Выбор сохраняется в localStorage; по умолчанию включена тёмная тема. Логотипы предоставлены владельцем проекта.

Фоны — игровые скриншоты Complementary Shaders (не скриншоты нашего сервера):
- День: https://www.complementary.dev/assets/img/newScreenshots/unbound1_coast.jpg
- Ночь: https://cdn.modrinth.com/data/HVnmMxH1/images/3c737e3c8c84d9875222196bb475fbb5b9367ed6.png

Источник указан в подвале сайта.
Адрес сервера и контакты публичны. Не добавляйте пароли или токены в `config.js`.

## Будущая вики

Модуль находится в `wiki/`, использует общую тему и навигацию, имеет собственный `wiki.css`.
Его можно расширять статьями или заменить статическим генератором документации,
сохраняя адрес `/wiki/`. Бэкенда, редактора и базы данных в текущей версии нет.
